# fiagdon-arenda.ru

Статическая версия сайта аренды коттеджей в Фиагдоне. Репозиторий не требует CMS, базы данных или сборки: для публикации достаточно отдать его содержимое любым статическим веб-сервером.

## Локальный запуск

```bash
python3 -m http.server 8080
```

После запуска сайт доступен по адресу `http://localhost:8080/`.

## Происхождение

Сайт восстановлен из более свежей очищенной копии старого cPanel-бэкапа. Исходный полный бэкап и второй домен в этот репозиторий намеренно не импортированы.

Из публикации исключены серверные настройки cPanel/Apache, проект Mobirise, системные файлы macOS/Windows и неработающие внешние интеграции. Подробности — в [MIGRATION.md](MIGRATION.md).
